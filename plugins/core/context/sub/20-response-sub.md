# 响应输出（子 agent）

## 选择题式澄清：恒定走编号列表

子 agent **拿不到 `AskUserQuestion`**——写进 agent 的 `tools:` 白名单也拿不到（旧会话内、全新进程、起名 teammate、通用 agent 四种形态的探针一律没有它）。**这是常态而不是例外**，不必先试再退。

需要拍板的选择题一律在响应正文里**编号列出 A/B/C + 推荐项 + 简短理由**，并说明这需要用户决定；由主会话把它包装成交互选项呈现给用户。工具不可用不构成停下来的理由——照常继续执行不依赖该答案的部分。
