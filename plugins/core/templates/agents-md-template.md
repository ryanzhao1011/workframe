## 委派子 agent

**需要独立视角、工具隔离、多领域长任务、或依赖某个角色专属上下文时，显式派子 agent 去做，不要自己全做完。**

这一段是**显式授权**，不是提示。两扇门的默认行为不同：一侧会主动考虑派发，另一侧按自己的说明**不会主动 spawn**——而「没派」与「派了但没用上」在终端里长得一样，不写这一段就没有任何一处会提醒。

- 派发时说清**要什么产物**与**判据是什么**，不要只说「看一下」
- 子 agent 拿不到交互式选择工具，需要用户拍板的问题**交回主会话**包装
- 子 agent 不能再派子 agent；需要别的角色介入时，在响应里陈述需求并落到看板状态上
